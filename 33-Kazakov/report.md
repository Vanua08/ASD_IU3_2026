## Задача 49 — суммы строк матрицы

### Идея решения и структуры данных

Матрица хранится в двумерном массиве `int[][]`. Создаётся массив `long[]` длины, равной количеству строк. При обходе матрицы каждый элемент прибавляется к сумме своей строки

Массивы соответствуют форме входных данных и результата, позволяют обращаться к элементам по индексу за `O(1)`. Тип `long` для сумм выбран потому, что сумма нескольких значений `int` может превышать диапазон `int`

### Расчёт асимптотики

Пусть `n >= 1` — число строк, `m >= 1` — число столбцов прямоугольной матрицы

- Создание массива сумм занимает `O(n)` времени
- Внешний цикл выполняет `n` итераций, внутренний — `m` для каждой строки, всего `n * m` прибавлений
- Время метода `sumRows`: `O(n + n * m) = O(n * m)`
- Дополнительная память метода с учётом возвращаемого массива: `O(n)`, без него — `O(1)`
- Чтение матрицы занимает `O(n * m)` времени, вывод сумм — `O(n)`, поэтому время программы целиком также `O(n * m)`
- Программа хранит входную матрицу и массив сумм, поэтому её общая память: `O(n * m + n) = O(n * m)`

### Примеры ручных тестов

Формат ввода: сначала `n m`, затем элементы матрицы по строкам. Каждая сумма выводится на отдельной строке

| Входная матрица | Ожидаемые суммы строк | Почему пример важен |
|---|---|---|
| `[[1, 2, 3], [-1, 0, 4]]` | `[6, 3]` | Прямоугольная матрица помогает обнаружить путаницу между строками и столбцами |
| `[[-5, -2], [-1, -9]]` | `[-7, -10]` | Проверяет обработку отрицательных чисел |
| `[[4], [0], [-2]]` | `[4, 0, -2]` | Проверяет один столбец и нулевую сумму |
| `[[2147483647, 2147483647]]` | `[4294967294]` | Проверяет одну строку и сумму, которая не помещается в `int` |
## Задача 50 — суммы столбцов матрицы

### Идея решения и структуры данных

Матрица хранится в `int[][]`, результат — в массиве `long[]` длины,
равной числу столбцов. При обходе матрицы каждый элемент прибавляется
к сумме своего столбца

Массив позволяет обращаться к нужной сумме по индексу за `O(1)`.
Тип `long` предотвращает переполнение суммы за пределы `int`

### Расчёт асимптотики

Пусть `n >= 1` — число строк, `m >= 1` — число столбцов

- Создание массива сумм занимает `O(m)` времени
- Вложенные циклы выполняют `n * m` прибавлений
- Время метода: `O(m + n * m) = O(n * m)`
- Дополнительная память метода с учётом результата: `O(m)`,
  без учёта результата — `O(1)`
- Чтение матрицы занимает `O(n * m)`, вывод — `O(m)`,
  поэтому время программы целиком — `O(n * m)`
- Общая память программы с учётом входной матрицы:
  `O(n * m + m) = O(n * m)`

### Примеры ручных тестов

Формат ввода и вывода аналогичен задаче 49,
но выводятся суммы столбцов в порядке их индексов

| Матрица | Ожидаемые суммы столбцов | Почему пример важен |
|---|---|---|
| `[[1, 2, 3], [-1, 0, 4]]` | `[0, 2, 7]` | Отличает суммы столбцов от сумм строк |
| `[[-5, -2], [-1, -9]]` | `[-6, -11]` | Проверяет отрицательные числа |
| `[[4, 0, -2]]` | `[4, 0, -2]` | Проверяет одну строку и ноль |
| `[[2147483647], [2147483647]]` | `[4294967294]` | Проверяет один столбец и необходимость long |
## Задача 51 — максимум в каждой строке матрицы

### Идея решения и структуры данных

Матрица хранится в `int[][]`, результат — в массиве `int[]`
длины, равной числу строк

Для каждой строки начальный максимум берётся из её первого
элемента. Остальные элементы сравниваются с текущим максимумом,
при обнаружении большего значения максимум обновляется

Начальное значение берётся из матрицы, чтобы правильно
обрабатывать строки, содержащие только отрицательные числа

Массив результата позволяет сохранить порядок строк.
Типа `int` достаточно, поскольку результат является одним
из исходных элементов и арифметические суммы не вычисляются

### Расчёт асимптотики

Пусть `n >= 1` — число строк, `m >= 1` — число столбцов

- Создание массива результатов занимает `O(n)` времени
- Для каждой из `n` строк выполняется `m - 1` сравнений
- Время метода: `O(n + n * (m - 1)) = O(n * m)`
- Дополнительная память метода с учётом результата: `O(n)`,
  без учёта результата — `O(1)`
- Чтение матрицы занимает `O(n * m)`, вывод — `O(n)`,
  поэтому время программы целиком — `O(n * m)`
- Общая память программы с учётом входной матрицы:
  `O(n * m + n) = O(n * m)`

### Примеры ручных тестов

Сначала вводятся размеры матрицы, затем её элементы.
Максимум каждой строки выводится на отдельной строке

| Матрица | Ожидаемые максимумы | Почему пример важен |
|---|---|---|
| `[[1, 9, 3], [8, 2, 4]]` | `[9, 8]` | Проверяет максимумы на разных позициях |
| `[[-5, -2, -9], [-1, -7, -3]]` | `[-2, -1]` | Обнаруживает ошибочную инициализацию максимума нулём |
| `[[4], [0], [-2]]` | `[4, 0, -2]` | Проверяет один столбец и ноль |
| `[[-2147483648, -2147483648]]` | `[-2147483648]` | Проверяет одну строку, равные элементы и границу int |
